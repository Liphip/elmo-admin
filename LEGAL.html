Keine Datensammlung durch diese App

Diese Anwendung ist eine rein client-seitige Webanwendung. Es werden keinerlei Daten an den Entwickler übertragen oder auf externen Servern des Entwicklers gespeichert.

Alle Datenverarbeitung findet ausschließlich im Browser des Nutzers statt:

  • API-Anmeldedaten werden optional im localStorage des Browsers gespeichert (nur wenn die Funktion „Anmeldedaten merken" aktiviert ist). Diese Daten verlassen nie den lokalen Browser.
  • Alle API-Anfragen werden direkt vom Browser des Nutzers an die Element IoT API gesendet. Es gibt keinen Zwischenserver.
  • Es werden keine Cookies gesetzt.
  • Es werden keine Tracking-Dienste wie Google Analytics oder ähnliche verwendet.
  • Es werden keine personenbezogenen Daten an den Entwickler weitergegeben.
  • Alle eingebundenen Bibliotheken (Bootstrap, Bootstrap Icons, jQuery, Leaflet) werden lokal ausgeliefert. Es erfolgen keine Anfragen an externe CDN-Dienste.

Kartendarstellung (Ansicht „Network“)

Nur beim Öffnen der Ansicht „Network“ lädt der Browser Kartenkacheln standardmäßig von OpenStreetMap (OpenStreetMap Foundation, St John’s Innovation Centre, Cowley Road, Cambridge, CB4 0WS, Vereinigtes Königreich). Dabei wird technisch bedingt die IP-Adresse des Nutzers an den Kachelserver übermittelt. Geräte- oder Messdaten werden nicht übertragen – angefragt werden ausschließlich Kartenausschnitte. Der Kachelserver kann in der Konfiguration geändert oder durch ein leeres Feld vollständig deaktiviert werden. Weitere Informationen: Datenschutzerklärung der OpenStreetMap Foundation.

Für die Datenverarbeitung durch die Element IoT API ist allein der Betreiber der Element IoT Plattform verantwortlich.
